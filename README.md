# 研写档案

考研英语二作文复盘和句型库。线上环境使用 Sites 运行 Worker，D1 持久化作文版本和学习标记，R2 按文件内容的 SHA-256 保存原图。数据和运行时密钥不进入代码仓库。

## 使用

从[研写档案](https://yanxie-english2.rainy20140.chatgpt.site)使用站点所有者的 ChatGPT 账号进入。数据管理页可编辑、归档恢复、下载备份或导入 V5 导出文件。重复的作文 ID 默认跳过，导入的旧句型状态只填补当前账号尚未设置的字段。

新的 Work 聊天可通过站点插件查询和新增作文。新增时给每次练习使用稳定的唯一 ID，使用既有 ID 会返回冲突。手写原稿、人工辨读的存疑标记、批改、改写和译文分别录入。缺少的原始材料留空，显示待补充。上传原图须传原始 JPG、PNG 或 WebP 图片的 data URL，也可使用数据管理内的图片选择器。

## 开发

需要 Node.js 24，无第三方包。

- `npm run dev` 运行本地预览，默认端口 3000，方便调试。使用内存 SQLite 和图片存储。本地预览注入测试身份，不能用作生产服务。
- `YANXIE_DEV_SEED=/绝对路径/备份.json npm run dev` 使用已有资料预览。将备份置于仓库以外。
- `npm test` 检验受控读写、原图还原、学习状态隔离、版本冲突和新增。
- `npm run build` 生成部署模块 `dist/server/index.js`。部署使用 `.openai/hosting.json` 中的 Sites 项目。源代码与 Sites 托管源同步，GitHub Pages 不承担私有数据库或图片鉴权。

生产环境使用 Sites 的站点访问策略和验证后的登录身份。运行时秘密 `OWNER_EMAIL` 用于限制内容和写入为所有者本人。可选的 `MIGRATION_KEY` 仅用于受控迁移与验收，必须由部署环境提供；服务身份的学习状态独立，浏览器无法读取。扩展数据库时在 `drizzle/` 追加迁移文件，勿改写已经应用的迁移。
